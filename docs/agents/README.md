# Agent Onboarding Lane

Status: active seed lane.

This folder holds the first-read files for a new or resuming AI agent working
on DotTalk++ / x64base.

Start here:

1. `AI_BABY_BOOTSTRAP_CARD.md`
2. `CURRENT_TARGET.md`

The bootstrap card teaches the agent the project doctrine, safety rules, and
first-read path. `CURRENT_TARGET.md` tells the agent what to work on now.

These files orient an agent. They do not authorize mutation by themselves.
