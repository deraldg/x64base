# DotTalk++ Student Manual

Working title: **DotTalk++ Student Manual: Learning Databases by Opening the Engine**

Purpose: teach database concepts through safe, visible DotTalk++ examples.

Audience: students, self-learners, instructors, curious programmers, database beginners.

Evidence rule: student labs should use runtime-proven, report-proven, HELP-documented, or clearly labeled material.

Blocked sections include work areas, SET/filter/index labs, ERSATZ labs, and HELP labs until their review items are resolved.
