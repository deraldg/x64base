## Summary

An expression is something the engine evaluates to produce a value.

- Kinds of expressions
- numeric
- character
- date
- logical
- Examples
- 1 + 2
- UPPER("abc")
- GPA + 0.01
- DATE() + 2
- LNAME = "TAYLOR"
- Commands using expressions
- CALC
- EVAL
- REPLACE
- IF
- LOCATE
- SMARTLIST
- Teaching point
- Expressions produce values.
- Predicates are expressions whose value is true or false.
