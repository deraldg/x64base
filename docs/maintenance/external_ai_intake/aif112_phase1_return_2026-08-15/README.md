## One thing worth knowing before reading either document

The evidence return contains a recorded scribe error. An interim report to the
owner claimed "all six steps passed" when Step 4 as specified -- ledger-level
check-and-insert sharing one FLOCK scope -- had not been run at all. What had
been proven was the FLOCK primitive beneath it. It was caught by re-reading the
steward's own template, not by the runtime, and corrected before transmission.

It is written into the return rather than quietly fixed because this lane
already carries one registry entry about a proof process passing something on
inadequate evidence (`proof.governance.availability_is_not_adoption`), and
filing a second instance silently would be the same failure a third time.
