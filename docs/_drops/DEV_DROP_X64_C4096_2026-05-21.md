# DotTalk++ X64 C(4096) Dev Drop

Purpose: add X64-only extended character field length support so `CREATE X64 ... C(4096)` can be accepted without changing classic DBF/VFP semantics.

## Replacement files

Copy these into the dev repo root:

- `src/cli/cmd_create.cpp`
- `include/xbase/dbf_create.hpp`
- `src/xbase/dbf_create.cpp`
- `include/xbase.hpp`
- `include/xbase_64.hpp`
- `include/xbase_vfp.hpp`

## Intended scope

- Classic/MSDOS/FoxPro/VFP `C(n)` remains capped at 255.
- X64 `C(n)` may exceed 255, with `C(4096)` as the current target case.
- Legacy field descriptor length byte remains compatibility-sized.
- X64 metadata carries/restores the true field length.

## Suggested smoke test

```text
DO SANDBOX
CREATE X64 memo_lines (memo_key C(80), line_no I, line_text C(4096))
STRUCT
APPEND BLANK
REPLACE memo_key WITH "TEST", line_no WITH 1, line_text WITH "ABC"
LIST
CLOSE
USE memo_lines
STRUCT
LIST
```
