Arctic

Legacy route for the Arctic TUI code name.

Legacy route

Arctic is the current code name for the DotTalk++ Workbench TUI surface.

This page is kept for older links. Use Arctic TUI for the current documentation page and Parallel GUI/TUI for the broader Workbench interface lane.

The family group is DotTalk++ Workbench. Arctic should not be used as the umbrella name for all GUI, browser, shell, and workflow surfaces.

Its subject is the terminal/TUI presentation layer around the runtime:

  • TUI menus and panels.
  • Tuple grids and record popups.
  • Command/output panes in the TUI shell.
  • Keyboard-driven workbench interaction.

Runtime screenshots for the current Arctic TUI evidence lane are collected in the LabTalk Runtime Evidence Gallery.

Real local command surfaces and workflow anchors include:

BUILDLMDB
BUILDLMDB CLEAN YES
BUILDLMDB FORCE YES
REINDEX
CMDHELPCHK
CMDHELPCHK REF
WORKSPACE OPEN DBF
WORKSPACE OPEN DBF CDX
WORKSPACE SAVE <name>
WORKSPACE LOAD <name>

DotScript scripts, smoke checks, maintenance lanes, GUI previews, and generated proposal packages belong under the broader DotTalk++ Workbench family, not under Arctic unless they are specifically TUI-facing.

See Current Project Truth and SelfDoc Website Publication, plus the canonical public repo deraldg/x64base.
