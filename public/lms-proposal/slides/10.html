The xBridge Data Flow

A chronological view of a learner's journey across all three systems

x64base DotTalk++ LabTalk xBridge
Event 1 · x64base
Onboarding
Enrollment, profile creation, prerequisite verification, cohort assignment
POST /learners · PUT /cohorts/{"{id}"}/enroll · xBridge event: learner.enrolled
Event 2 · DotTalk++
Orientation
Cohort introduction thread, expert mentor match, orientation video session
xBridge trigger: learner.enrolled → DotTalk++ webhook → channel.join + mentor.match
Event 3 · x64base + DotTalk++
Curriculum Engagement
Lesson completion triggers discussion thread prompts and expert office-hour availability
xAPI: lesson.completed → xBridge routes to DotTalk++ async channel + officehours.unlock
Event 4 · LabTalk
Lab Assignment
x64base issues lab access token; LabTalk session data streams back as xAPI statements
GET /lab-token (JWT) → LabTalk LTI 1.3 launch · xAPI: lab.attempt.started → xBridge
Event 5 · LabTalk → x64base
Competency Assessment
Lab score triggers credential issuance or remediation pathway in x64base
xAPI: lab.score.submitted → xBridge → POST /credentials or PUT /pathway/remediation
Event 6 · x64base
Program Completion
Consolidated transcript, compliance certification, and alumni DotTalk++ channel access granted
GET /transcript/consolidated · POST /compliance-cert · DotTalk++: alumni.channel.grant
