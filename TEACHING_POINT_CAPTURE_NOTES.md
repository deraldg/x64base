# How to capture a new teaching point

Add a row to:

```text
docs/teaching/teaching_points_v1.csv
```

or add a section to:

```text
docs/teaching/TEACHING_POINT_LEDGER.md
```

Minimal capture form:

```text
Teaching point:
Audience:
Feature area:
Evidence class:
Promotion target:
```

Recommended TPID format:

```text
TP-YYYYMMDD-NNN
```

Example:

```text
TP-20260528-005
```

Evidence rule:

```text
A teaching point can start as an IDEA or DESIGN_INTENT, but it must be checked before promotion into manuals, HELP, Data Dictionary evidence, or diagrams.
```
