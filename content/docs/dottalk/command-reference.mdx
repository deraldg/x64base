This snapshot is deployed, and the published pages were read back from the live
origin afterwards rather than assumed. The release number and source commit it
shipped in are not named here: the publisher writes them into
`/artifacts/site-release.json` and then verifies that against the live site, so
a number typed into this sentence could only be one publish from being wrong.

**HELP lines fell 29,700 to 18,566, and that is a duplicate leaving the store,
not content leaving it.** The harvest had been carrying the usage-contract family
twice: two separate scans covered the same block of source text and wrote rows
whose only difference was the evidence string recording which scan found them, so
the de-duplication key never matched and both copies survived every export.
Removing one copy took artifacts and sections from 14,844 to 10,587 apiece -- the
two stay one-to-one at both ends, which is how the removal is known to be clean
-- and took contract drift from sixteen instances to zero.

The other three figures moved the other way, and for the ordinary reason:
**commands rose 462 to 464, reachable topics 666 to 669, and argument rows 2,368
to 2,378.** The engine gained content while the harvest shed a duplicate of it.
The website catalog rose 239 to 241 in the same pass, admitting `GROUPCOMMIT` and
`WORKDESK`, both of which carry usage contracts in source and neither of which
had a catalog row.

Of the fourteen tables in the canonical harvest, **ten are exported from the
current store and four are carried forward from stale May seeds** --
`META_SYSENTVAR`, `META_SYSFLDDIC`, `META_SYSHELP` and `META_SYSMSG`, whose
sources are not yet current. Earlier snapshots on this page reported 14 of 14,
which read "matches the store" as though it meant "exported from the store".
Those are different claims and this page now separates them.

The command catalog, function catalog, error codes and locale tables were all
re-checked against source on 2026-09-14: 241/241 with zero fallback, 77 core
functions plus 2 self-registered, 20 error codes, 5 locales.

## Authority and regeneration

This landing page is a reviewed derivative. Public source, runtime behavior,
HELP/CMDHELP, usage contracts, and the accepted manualgen artifacts remain the
technical evidence.

When command registration, HELP, contracts, or manual sections change, the
reference must be reharvested, validated, reviewed, and accepted before this
snapshot is advanced. Website prose alone cannot promote a command or change
its support status.
