# pycrud Help

- **File -> Connect...**: select a SQLAlchemy URL and connect (SQLite by default).
- **File -> Open Text/CSV...**: preview and (for CSV) import to a new table.
- **View -> Table**: choose current table (teachers / students / courses / enrollments).
- **Edit -> New / Edit / Delete**: CRUD on the current table.
- **Tools -> SQL Console**: run ad-hoc SQL and view results.
- **Tools -> Compute Column...**: add a new column from a formula (safe AST).
- **Relational -> Join / Project / Select**: relational helpers (in-memory or SQL).
- **DotTalk++**: future integration; configure the backend URL later.
