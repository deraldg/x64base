# LabTalk Proofs

Runtime transcripts and proof artifacts generated by LabTalk portal/lab runs.

Recommended subfolders:

- `runs/` - captured runtime output from portal-launched scripts
- `reports/` - curated proof summaries
- `snapshots/` - generated static readbacks

Proof artifacts should state what was run, what runtime produced the output, and
whether the result is student-ready, review-needed, or simulation-only.
