Developer manual publication refreshed

2026-07-09Category: press-releases

The publication lane now carries the newer workbench, indexing, and relations doctrine instead of the earlier scaffold text.

The developer manual publication lane has been refreshed so the public reader no longer lags behind the current source-manual work.

The update tightens several areas:

  • navigation and browsing now state clearly that GUI and browser layers are projection surfaces over runtime truth
  • indexing prose now preserves the open architecture distinction between canonical runtime indexing and teaching/lab index lanes
  • relations and tuple views now explain ownership instead of relying on a placeholder section

This matters because the site, manuals, and runtime documentation need to tell the same story. The point is not to make every publication layer identical. The point is to stop the stable reader from drifting behind the working architecture.
